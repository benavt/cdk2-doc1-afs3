# CDK2–DOC1 structural atlas

All 2,000 archived AFSample3 models, separate all-residue PCA/UMAP/t-SNE analyses, and exact original coordinates.

ProteinEBM colors appear only after acceptance of all scores for the construct. Learned arbitrary units; lower within construct.

The saved-atlas interface is generated from Structure_Clustering. Plotly.js and 3Dmol.js provide plotting and molecular display.
