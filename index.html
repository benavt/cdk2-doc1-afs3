Methods & provenance

Sampling methods, analysis settings and frozen source identities.

Each target contains all 1,000 archived AFSample3 samples: 200 seeds × 5 samples. Constructs are analyzed separately, using every Cα residue of both chains. No terminal trimming is applied.

ProteinEBM Model 6 expert energies score the complete two-chain construct at 16 conditioning levels. Color by exposes t=0.10 after all 1,000 scores for that construct are accepted. Values are learned arbitrary units, with lower values ranked first within one construct. They are not calibrated binding energies and are not comparable across constructs.

Cluster representatives are the models with the highest saved AF3 ranking score within each cluster; ties use canonical model identity. They are not claimed to be structural medoids. Cluster populations describe generated samples, not equilibrium probabilities.

Sources: AFSample3 · ProteinEBM. Original coordinates and a complete membership/score CSV are available for each construct.

Bonsai (CC BY-NC 4.0) uses all 1,000 models of each construct and the same complete Cα-distance features. All nonzero centered PCA axes are retained without whitening or variance scaling; native reconstruction uses kNN=10. One tree per construct supplies three native layouts and is reused across the saved clustering views. The optional Bonsai tree-group colors are exploratory native edge cuts chosen by in-sample tree-path silhouette; they do not replace the Primary or HDBSCAN memberships.

Bonsai controls

The Bonsai tree contains all 1,000 original models of the selected construct, including HDBSCAN unassigned models. The same native tree is reused across the Primary and HDBSCAN views. Tree-path distances summarize structural differences; the drawing root is arbitrary. Colors follow the shared legend.

Hover or focus a point for model details; Enter or Space selects it. Drag to pan and scroll to zoom. Tree layout switches among the three saved layouts. Reset plot restores the view; Save PNG exports it.
